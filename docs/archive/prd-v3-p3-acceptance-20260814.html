🤖 语义任务工作流

1. Duke 看板上点 "🤖 AI 摘要"
2. 浏览器 POST /api/agent/ask · 写 ~/.bidboard/agent_queue/req_xxx.json
3. 推 SSE agent_request · 浏览器 toast 提示
4. Mavis(AI Agent) 拉队列 /api/agent/queue 处理
5. Mavis 读 bid 数据 → 生成摘要 → POST /api/agent/answer
6. 推 SSE agent_answer · 浏览器自动刷新显示

优势:不依赖 LLM API,语义由 Mavis 灵活处理,可重试/中断/批量

📱 飞书/微信推送

P0 客户 stage/block 变化时:
1. _check_p0_alert 推 SSE p0_alert
2. 后台线程调 lark_push.sh
3. lark_push.sh 读 config + 构造富文本
4. POST 到 webhook URL
5. 失败/无 config 优雅降级,日志记录

优势:无 SDK 依赖,直接 curl,异步不阻塞,@ 提醒手机号
