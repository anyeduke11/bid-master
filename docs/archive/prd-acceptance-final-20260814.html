4本次会话关键修复 (3 个 bug)

🐛 #1 SSE UnboundLocalError (CRITICAL)

_broadcast() 内 SSE_CLIENTS = [...] 重新绑定使 Python 视为局部变量,for 循环在赋值前读取触发 UnboundLocalError。修复:加 global SSE_CLIENTS + slice 赋值 SSE_CLIENTS[:] = [...]。

影响:F-P0-06 跨 tab 实时同步全部失效

🐛 #2 do_PATCH 缺校验

do_PATCH 没校验 body 是否含 value 字段,缺字段时静默把字段置 null,污染数据。修复:返回 400 missing 'value' field。

影响:数据完整性 · 错误信息明确化

🐛 #3 缺 /api/bids/{code} 单条 GET

window.BidBoard.read(code) 原实现是 fetch 全表再 find,效率低且依赖全表权限。新增 /api/bids/{code} 端点,直接返回单条 bid 或 404。

影响:F-P0-04 7 方法效率提升 · 权限粒度更细

🛠 #4 start.sh / stop.sh pkill 模式错误

原 pkill -f "bid-board-server" 匹配不到 (Python 进程名是 "Python"),旧进程不能被替换,新进程绑端口失败。修复:多模式匹配 (bid-board-server / python3 server.py / Python server.py)。

影响:服务重启可靠性
