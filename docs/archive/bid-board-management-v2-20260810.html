bids 表 Schema

-- bids 表:投标看板数据源
CREATE TABLE bids (
  code        TEXT PRIMARY KEY,         -- 客户代号,如 nfh2026
  client      TEXT NOT NULL,            -- 客户名
  stage       TEXT CHECK(stage IN ('跟踪','审查','报价','修订','封标','述标')),
  priority    TEXT DEFAULT 'P2' CHECK(priority IN ('P0','P1','P2')),
  due_at      TEXT,                       -- 截止时间
  ai_ready    JSON DEFAULT '[]',    -- AI 就绪项数组
  human_todo  JSON DEFAULT '[]',    -- 人要做的事
  block       TEXT DEFAULT '',        -- 阻塞
  last_sync   TIMESTAMP,                  -- 最后同步时间
  timeline    JSON DEFAULT '[]'     -- 事件时间线
);

节点配置

截止日期自动识别规则

系统按 "截止日期 − N 天" 自动反推每个节点的截止日。
负数 = 截止后 N 天(如讲标 D-1、公示 D+30、复盘 D+60)

示例: 截止 2026-08-13 17:00
报价 → 2026-08-03 D-10
初稿 → 2026-08-06 D-7
定稿 → 2026-08-10 D-3
封标 → 2026-08-13 D-0
手动识别: 节点详情弹窗可手动调整截止日期,优先级高于自动规则。
