5新 API 清单
端点方法作用
/api/bids/{code}/pausePOST暂停客户(可写 reason)
/api/bids/{code}/resumePOST恢复(paused → active)
/api/bids/{code}/closePOST关闭(final_outcome=win/loss/no-bid, loss_reason 可选)
/api/bids/{code}/reopenPOST重开(closed → active)
/api/bids/{code}/archivePOST归档(closed → archived)
/api/bids/summaryGET4 状态聚合 {active, paused, closed, archived, total}
/api/bids?status=...GET按状态过滤(active/paused/closed/archived/all)
/api/summary?period=...GET时间维度(week/month/quarter/year)+ 业务维度
/api/logs?level=&module=&code=&keyword=GET4 维过滤
/api/playbooks/runPOST跑剧本(script 模式 subprocess.run / inline 模式 lambda)
